# Collaborator preferences

- Short, direct replies. Bullets over long paragraphs.
- Verify before claiming. Prefer a command output over a guess.
- Public copy: precise, no em dashes, no hype stack.
- Keep the product honest about what is assisted, manual, or not built.
- Commit in small, logical steps. Do not commit generated output or local secrets.
- For a public repo, optimize the first screen and the install path.
